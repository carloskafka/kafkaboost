        Help
        
            
        Questions
        
            
        Short answers. The full documentation has the details.
        
          
        
        
        
        
        
          
        What does this app change?
        Only ThrottleStop's profile (undervolt, boost caps, power limits), a startup task for ThrottleStop and, if you choose, the VBS/hypervisor setting. It does not touch game files.
        
          
        Is it safe?
        Every change is backed up and reversible from Restore. Still, changing CPU voltages can cause instability: this chip logged a corrected CPU error at −100 mV, so the app never goes deeper.
        
          
        Do I have to keep the app open?
        No. ThrottleStop starts at every logon and a 5-minute watchdog keeps it running. Open the Dashboard after a Windows update to check that the tuning is still in place.
        
          
        Why does it ask to turn VBS off?
        Windows blocks voltage changes while virtualization-based security is on. Turning it off is a security trade-off and breaks WSL2/Docker until you restore it.
        
          
        Will it work on my laptop?
        The values are specific to the Lenovo Legion 83DE with an i9-14900HX. On another CPU the app explains why it will not apply them.
