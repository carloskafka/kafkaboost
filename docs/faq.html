FAQ

Short, honest answers.

Is it really free?

Yes. There are no plans, prices, accounts or licence keys.

Will it raise my FPS?

Nobody can promise that and this project does not. FPS was never measured here. What was measured is a lower CPU temperature and no thermal throttling on one laptop.

Is it safe?

It is built to be careful: a restore point first, a saved previous value for each tweak, and a risk badge on each card. But changing system settings always carries some risk, and the risky tier can lower your security. Read each description.

How do I undo a change?

Switch the tweak off: the saved previous value is restored. The Restore screen rolls back the CPU tuning, and you can open System Restore from the app.

Does the CPU tuning work on my processor?

No. It was validated only on a Lenovo Legion 83DE with an i9-14900HX and the app refuses other CPUs for it. Undervolt values are specific to each chip. The Windows tweaks are separate and do not depend on the CPU.

Why does the CPU tuning turn off VBS?

Voltage controls are locked while virtualization-based security is on. Turning it off is your choice, the consequences are listed, and it can be turned back on.

Does it run on macOS or Linux?

The code for a reduced feature set exists but was never run on either. Treat both as unsupported. Tweaks, Cleanup and Restore are Windows-only.

What data does it collect?

None. There is no telemetry or account. See the privacy page.

Where is the installer?

No release with an installer is published yet. Use KafkaBoost.cmd from the source for now; see Download.

Something broke. What now?

Switch the tweak off, or use the restore point. Then open an issue on GitHub with what you did.
