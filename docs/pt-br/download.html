    Rodar do código-fonte (Windows)

    1. Instale o Node.js e o Git, depois clone o repositório (ou baixe o ZIP no GitHub).
    2. Dê dois cliques em KafkaBoost.cmd na raiz do repositório. Ele abre o app com direitos de administrador; a primeira execução instala as dependências do app.
    3. Para o ajuste térmico da CPU só no Legion 83DE, você também pode dar dois cliques em install.cmd (ele pede elevação sozinho).
    git clone https://github.com/carloskafka/legion-14900hx-throttlestop.git
cd legion-14900hx-throttlestop
KafkaBoost.cmd

    O app precisa de direitos de administrador para alterar configurações do sistema. Rodar do código-fonte não instala nada em todo o sistema.

    Requisitos

    • Windows 11 (testado no build 26300). Windows 10 e outros sistemas não foram testados.
    • Node.js para rodar do código-fonte. Um instalador empacotado está configurado, mas não foi publicado.
    • Para o ajuste térmico da CPU: um Lenovo Legion 83DE com Intel Core i9-14900HX. O app recusa outras CPUs nesse recurso.
    Atenção: o ajuste térmico da CPU exige a segurança baseada em virtualização desligada, o que enfraquece uma proteção do Windows e quebra o WSL2 e o Docker até ser restaurada. O app nunca faz isso sem o seu consentimento.

    Depois de instalar

    Abra o Painel, rode uma verificação e revise a tela de Otimizações antes de ligar qualquer coisa.
