    Run from source (Windows)

    1. Install Node.js and Git, then clone the repository (or download the ZIP from GitHub).
    2. Double-click KafkaBoost.cmd in the repository root. It starts the app with administrator rights; the first run installs the app’s dependencies.
    3. For the CPU thermal tuning on the Legion 83DE only, you can also double-click install.cmd (it self-elevates).
    git clone https://github.com/carloskafka/legion-14900hx-throttlestop.git
cd legion-14900hx-throttlestop
KafkaBoost.cmd

    The app needs administrator rights to change system settings. Nothing is installed system-wide by running from source.

    Requirements

    • Windows 11 (tested on build 26300). Windows 10 and other systems are untested.
    • Node.js to run from source. A packaged installer is configured but has not been published.
    • For the CPU thermal tuning: a Lenovo Legion 83DE with an Intel Core i9-14900HX. The app refuses other CPUs for that feature.
    Be aware: the CPU thermal tuning needs virtualization-based security turned off, which weakens a Windows protection and breaks WSL2 and Docker until restored. The app never does it without your consent.

    After installing

    Open Dashboard, run a check, and review the Optimizations screen before switching anything on.
