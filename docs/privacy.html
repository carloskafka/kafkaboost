Privacy

KafkaBoost has no accounts and no telemetry. This page says exactly what is stored and what leaves your PC.

What we collect

Nothing. The app has no analytics, no crash reporting, no account and no licence check. We do not receive any data from it.

What is stored on your PC

  • App settings (theme, language, tray options) in a settings file in the app’s user-data folder.
  • The previous value of each tweak, in %ProgramData%\LegionTuning\state.json, so it can be reverted.
  • Timestamped backups of ThrottleStop.ini and logs, in folders you can open from Settings and delete.

What can leave your PC

  • Update check: only when you start it, the app asks GitHub for the latest release, which sends your IP address like any web request. The app contacts github.com only when you check for updates or press Download and install.
  • ThrottleStop download: only when you click it, the app opens or fetches the download from TechPowerUp.
  • Winget and similar tools, if you use them, talk to their own servers; KafkaBoost does not see that traffic.

This website

The site sets no cookies and has no analytics or ads. It is hosted on GitHub Pages, which keeps its own server logs. The Download page may ask api.github.com for the latest release from your browser; if you block scripts, the page still works.

Contact
